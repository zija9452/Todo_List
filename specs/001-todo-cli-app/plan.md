## Summary

Implement a command-line interface todo application in Python that supports add, delete, update, list, and toggle completion of tasks with sorting capabilities. The application will use in-memory storage only and follow the CLI contract: `todo add|list|update|delete|toggle` with `--sort {title,priority,due,created}` and `--order {asc,desc}` options. All code will be agent-generated with comprehensive unit tests following a test-first approach.
